# Digital Gram Panchayat Assistant

A web-based platform connecting villagers with Gram Panchayat services.

## Technologies
- React + Vite
- Node.js + Express
- MySQL
- React Leaflet + OpenStreetMap

## Main Features
- User registration and login
- Complaint submission and tracking
- Photo and location uploads
- Admin dashboard
- Government schemes and announcements
- English and Telugu support
